# MyTTS · подготовка книг к озвучке голосами персонажей

Скрипт для компьютера. Указываете книгу EPUB, получаете файл `.mytts-book`. Загружаете его в MyTTS, и при
чтении этой книги (в Moon+ Reader или другой читалке) реплики главных персонажей звучат их собственными
голосами. Второстепенные персонажи читаются общими голосами «прочих» (мужским и женским), повествование —
голосом автора.

Нужна MyTTS 5.0.4 Beta 2 или новее: в ней есть раздел «Книги с голосами персонажей».

## Как пользоваться: по шагам

### 1. Установить (один раз)

Нужен Python 3.9 или новее (macOS и Linux — обычно уже есть; Windows — https://www.python.org/downloads/,
при установке отметьте «Add python.exe to PATH»).

```sh
git clone https://github.com/davnozdu/mytts-books.git
cd mytts-books
python3 -m venv venv
venv/bin/pip install -r requirements.txt
```

Windows (PowerShell или cmd):

```bat
git clone https://github.com/davnozdu/mytts-books.git
cd mytts-books
python -m venv venv
venv\Scripts\pip install -r requirements.txt
```

Без git можно скачать архив: кнопка **Code → Download ZIP** на странице репозитория.

### 2. Получить ключ LLM (один раз)

Нужен ключ одного провайдера:

| Провайдер | Где взять ключ | Что вписать в `.env` | Модель по умолчанию |
|---|---|---|---|
| Ollama Cloud (по умолчанию) | https://ollama.com/settings/keys | `OLLAMA_API_KEY=...` | `deepseek-v4.1-flash` |
| API DeepSeek (`--provider deepseek`) | https://platform.deepseek.com/api_keys | `DEEPSEEK_API_KEY=...` | `deepseek-flash` |
| Groq (`--provider groq`) | https://console.groq.com/keys | `GROQ_API_KEY=...` | `qwen/qwen3.8-27b` |

Скопируйте файл `.env.example` в `.env` (в той же папке) и впишите ключ после знака `=`. Файл `.env` не
попадает в git, скрипт ключ никуда не записывает и не выводит. Вместо файла можно задать переменную
окружения (`export OLLAMA_API_KEY=...`, в PowerShell `$env:OLLAMA_API_KEY="..."`).

### 3. Обработать книгу

```sh
venv/bin/python mytts_book.py process "путь/к/книге.epub"                        # Ollama Cloud
venv/bin/python mytts_book.py process "путь/к/книге.epub" --provider deepseek    # API DeepSeek
venv/bin/python mytts_book.py process "путь/к/книге.epub" --provider groq --no-think  # Groq (Qwen), бесплатно
```

Windows: `venv\Scripts\python mytts_book.py process "C:\Книги\книга.epub"`.

Скрипт показывает пять шагов (кандидаты → LLM → проверка → голоса → файл) и в конце печатает путь к готовому
файлу, по умолчанию `out/<имя книги>/<название>.mytts-book`. Роман обрабатывается за несколько минут, сборник
рассказов — до десяти-пятнадцати (см. «Время» ниже). Если прервать или сеть оборвётся — запустите ту же
команду ещё раз: уже полученные ответы не запрашиваются повторно.

### 4. Загрузить в MyTTS

1. Перенесите файл `.mytts-book` на телефон (кабель, облако, мессенджер — любым способом).
2. В MyTTS: **настройки LLM → мультиголосовая озвучка** (включите её и LLM-обработку) **→ «Книги с голосами
   персонажей» → «Загрузить файл книги»** и выберите файл.
3. Там же в **«Персонажи и голоса»**: у каждого персонажа можно сменить голос и нажать «Прослушать»;
   переключатели «Голос автора — свой для этой книги» и «Голоса прочих — свои для этой книги» задают голоса
   автора и «прочих» один раз на всю книгу (или остаются общими из настроек мультиголоса).

### 5. Читать

Откройте эту же книгу в Moon+ Reader (или другой читалке с озвучкой через Android TTS) и включите чтение
голосом MyTTS. MyTTS узнаёт книгу и главу по самому тексту — имя файла и название значения не имеют. На экране
«Книги с голосами персонажей» видно, какая книга и глава сейчас узнаны.

Файлом `.mytts-book` можно делиться: в нём нет текста книги, только персонажи и отпечатки предложений. Кнопка
«Поделиться» есть у каждой книги в MyTTS.

## Как это работает

1. **Кандидаты.** Скрипт сам находит в книге имена, фамилии, отчества, уменьшительные формы, прозвища и
   обращения («князь», «генеральша»). Формы приводятся к именительному падежу (морфология pymorphy3),
   считаются упоминания и реплики («— сказал князь»), определяется пол. Правила общие для любой книги.
2. **Сопоставление в LLM.** LLM получает только список кандидатов с короткими примерами (не всю книгу) и
   решает, какие формы означают одного персонажа. Второй запрос проверяет каждую склейку. Всё сомнительное
   уходит в «прочие»: лучше не дать персонажу своего голоса, чем склеить двух разных людей.
3. **Проверка ответа.** Скрипт отбрасывает выдуманные номера, повторы, склейки, противоречащие полу, и
   обращения, которые относятся к нескольким персонажам.
4. **Голоса.** Главным персонажам (говорят или часто упоминаются) раздаются голоса по полу.
5. **Файл для MyTTS.** Персонажи, их формы имён, пол, рекомендованные голоса и отпечатки предложений
   (хеши, по которым MyTTS узнаёт книгу и главу во время чтения). **Текста книги в файле нет.**

Роман или сборник рассказов определяется по оглавлению: в сборнике у каждого рассказа свои персонажи и свой
короткий запрос.

## Параметры

| Параметр | Что делает |
|---|---|
| `--provider deepseek` | API DeepSeek вместо Ollama Cloud |
| `--provider groq` | Groq (Qwen 3.8 27B) — бесплатный тариф, см. «Groq и его лимиты» |
| `--no-think` | без размышления: в 5–15 раз быстрее, но меньше верных склеек (по умолчанию размышление включено) |
| `--model NAME` | другая модель провайдера, например `deepseek-v4-pro` для DeepSeek, `openai/gpt-oss-120b` для Groq |
| `--endpoint URL` | свой адрес сервиса (например, Ollama на своём компьютере: `http://localhost:11434`) |
| `--parallel N` | одновременных запросов (по умолчанию 1) |
| `--scope book` / `section` | принудительно роман / сборник, если определилось неверно |
| `--voices FILE` | список голосов модели с полом (по умолчанию `voices/silero_cis.json`, Silero CIS, 29 голосов) |
| `-o DIR`, `--output FILE` | рабочая папка и путь итогового файла |
| `--redo` | спросить LLM заново; без него уже полученные ответы переиспользуются |

## Время и качество

Замерено 8 октября 2026, Ollama Cloud, `deepseek-v4.1-flash`, запросы по одному:

| Книга | С размышлением (по умолчанию) | `--no-think` |
|---|---|---|
| «Идиот», роман, 200 кандидатов | ~3 мин | 12 с |
| «Ночной взгляд», сборник из 20 рассказов | ~10 мин | 31 с |

Извлечение кандидатов занимает 1–2 секунды; остальное — ответ LLM. С размышлением на «Идиоте» склеено
больше верного («Лебедев = Лукьян Тимофеич», «Коля = Николай Ардалионович», «Птицын = Иван Петрович»,
«генеральша = Лизавета Прокофьевна») и ошибочных склеек не найдено; без размышления был пропуск этих связей
и одна ошибочная склейка двух разных людей. Поэтому размышление включено по умолчанию.

## Groq и его лимиты

Groq даёт бесплатный доступ к Qwen 3.8 27B (`--provider groq`), но тариф жёсткий — на этом канале стоит
обрабатывать небольшие книги, а не сборники. Лимиты free-тира (замерено 8 октября 2026):

| Лимит | Значение |
|---|---|
| Запросов в минуту | 30 |
| Запросов в день | 1000 |
| Токенов в минуту | 8000 (в т. ч. выходных — около 1000) |
| Токенов в день | 200 000 |
| Предел ответа модели | 16 384 токена (больше Qwen 3.8 27B не отдаёт) |

Что из этого следует:

- **Темп.** Скрипт сам режет запросы: на Groq не чаще 10 в минуту (на Ollama/DeepSeek — 120). Даже с
  `--parallel`, потоки встанут в очередь и не пробьют лимит одновременно.
- **Размышление дорого по токенам.** При лимите в 8000 токенов/мин одна книга с размышлением упирается в
  потолок быстро. Для Groq есть `--no-think`: без размышления та же книга проходит по токенам заметно
  дешевле (размышление тратит сотни токенов на каждый абзац). С размышлением — только небольшой рассказ.
- **429 — не ошибка.** Если лимит всё же пробит, скрипт ждёт `retry-after` от Groq и повторяет сам (до трёх
  раз на запрос). Прерывать не надо.
- **Роман на Groq за один день может не пройти** по токенам (200K/день). Запускайте повторно: готовые ответы
  сохраняются, досчитаются оставшиеся. Для больших книг лучше Ollama Cloud или DeepSeek.
- **Помните про User-Agent.** Запрос к Groq без заголовка User-Agent ловит 403 от Cloudflare (не 401).

## Что отправляется в LLM

Только список кандидатов: номер, найденная форма имени, число упоминаний и реплик, пол, обращения и по
одному-два коротких примера из текста (около 150 знаков вокруг имени). Книга целиком не отправляется.
Запросы можно прочитать в рабочей папке (`llm_prompt_*.txt`).

## Отдельные шаги

`process` выполняет их подряд; можно запускать по одному, например чтобы поправить ответ LLM вручную.

```sh
python mytts_book.py extract book.epub -o out/book   # кандидаты и запросы к LLM (секунды)
python mytts_book.py llm out/book                    # ответы в out/book/answers/
python mytts_book.py apply out/book                  # проверка → cast.json, отчёт что снято и почему
python mytts_book.py voices out/book                 # раздача голосов
python mytts_book.py export out/book                 # → .mytts-book
```

Файлы рабочей папки:

- `candidates.json` — кандидаты с формами, упоминаниями, репликами, примерами;
- `llm_prompt_*.txt` — запросы к LLM;
- `answers/` — ответы LLM (`*.json`), проверка склеек (`*.verify.json`), время и токены (`*.meta.json`);
  ответ можно исправить вручную и снова выполнить `apply`, `voices`, `export`;
- `cast.json` — персонажи по разделам, «прочие», снятые проверкой склейки (`dropped`) и замечания;
- `book_index.json` — отпечатки предложений по разделам.

## Голоса других моделей

`voices/silero_cis.json` описывает голоса Silero CIS (12 мужских, 17 женских) и голоса автора и «прочих»
для раздачи на компьютере. MyTTS всё равно раздаёт голоса заново под модель, установленную на телефоне —
подсказки из файла используются, если такие голоса там есть. Для другой модели можно сделать свой файл в
том же формате и передать его через `--voices`.

## Если что-то не так

- **«Нет ключа»** — впишите ключ в `.env` (шаг 2).
- **`HTTP 401`** — неверный ключ; **`HTTP 429`** — превышен лимит провайдера, запустите позже: готовые
  ответы сохранены, повторный запуск продолжит с места остановки. (На Groq 429 скрипт отрабатывает сам.)
- **`HTTP 403` (error code: 1010) на Groq** — Cloudflare отклонил запрос; скрипт всегда ставит User-Agent,
  но если правите код сами — не убирайте этот заголовок.
- **`length` в выводе шага 2 и пустой ответ** — модели не хватило лимита на размышление; задайте больше,
  например `--max-tokens 120000`, и добавьте `--redo`.
- **Персонаж разделён на два или попал в «прочие»** — поправьте ответ в `answers/` и выполните `apply`,
  `voices`, `export`.
- **Сборник определился как роман (или наоборот)** — `--scope section` или `--scope book`.
- **MyTTS не узнаёт книгу при чтении** — убедитесь, что в MyTTS включены LLM-обработка и мультиголосовая
  озвучка, а текст в читалке — тот же, что в обработанном EPUB (другое издание с другим текстом не совпадёт).
